# E-Commerce Store

## 📌 Description
A full-stack multi-vendor e-commerce web application.

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB

## ✨ Features
- User Authentication (JWT)
- Product Listing
- Cart & Wishlist
- Order System
- Vendor Dashboard

## ⚙️ Setup Instructions

### Backend
cd backend  
npm install  
npm start  

### Frontend
cd frontend  
npm install  
npm run dev
